# Login form

Практична з інтернет-технологій: форма входу на HTML, CSS і JS.

Поля: ім'я, прізвище, електронна пошта, пароль. Усі обов'язкові. Чекбокс показує пароль у вигляді тексту.

Після натискання кнопки відкривається вікно, де введене ім'я виводиться по одній літері.

Запуск: відкрити `index.html` у браузері, сервер не потрібен.

Файли:
- `index.html`, `style.css` - розмітка і стилі
- `index.js` - обробка форми
- `alfabet/alfabet.js` - алфавіти
- `alfabet/success-reg.js` - вікно з іменем
